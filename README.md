# 💰 Expense Tracker (Python)

A simple command-line Expense Tracker built with Python. This project helps users keep track of their daily expenses by adding, viewing, searching, deleting, and saving expense records.

## 🚀 Features

* ➕ Add a new expense
* 📋 View all expenses
* 🔍 Search expenses by category
* 🗑️ Delete an expense
* 💵 Calculate total expenses
* 💾 Save expenses to a JSON file
* 🔄 Automatically load saved expenses when the program starts

## 🛠️ Built With

* Python
* Object-Oriented Programming (Classes)
* Functions
* Modules
* File Handling
* JSON

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/ExpenseTracker.git
```

2. Open the project folder:

```bash
cd ExpenseTracker
```

3. Run the program:

```bash
python main.py
```
